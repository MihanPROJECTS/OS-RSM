# OS-RSM

Open Source Resource System Monitor is a program for monitoring temperature and the usage of CPU, RAM, swap, and disk. It also displays selected information in your operating system's system tray.

##  Available functions
Click the small square in your OS system tray. A window will open allowing you to select tray modules. Choose the desired one from the list, and it will be applied to the system tray; you can then close the program, and it will continue running in the background.

###  BLOCKS
* **`CPU usage % (GREEN)`**
* **`RAM usage % (VIOLET)`**
* **`DISK usage % (YELLOW)`**
* **`SWAP usage % (BLUE)`**
* **`TEMPERATURE °C / °F (RED)`** 
* **`CUSTOM (GREY)`**
